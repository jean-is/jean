# Make an extension

An extension adds to what you do here: it watches what happens, guards actions, or shows a few lines above the box, under answers or on its own page in Settings. It runs in a sandbox of its own, with no internet, no files and no keys, and does only what its rights allow. You write it with `extension`; the user reads its rights and code on its page, then adds it. Nothing of it runs before.

## Steps

1. Take what the request gives: what should happen, when, and what the user should see. Decide the rest and keep going; ask one question only when two readings would make different extensions.
2. Ask for the fewest rights: `watch` to hook events at all, `draw` to show anything, `notify` for short messages, `change` to change an event or its answer, `refuse` to make an action more careful, and `loosen`, to let an action go ahead without asking, only when the user asked for exactly that.
3. Write `main.js` as one module that exports `async function register(on, $)`: no import, no fetch, no page or element of its own. Each event is answered within 5 seconds.
4. Every word it shows is in the user's language; numbers and dates through `Intl`.
5. Call `extension` with its name (lowercase letters, digits and dashes), title and description in the user's language, its rights, an icon among the app's glyphs when one fits (moon, globe, star, bell), and the code.
6. Say in two lines what it does and that its page is open: the user reads what it may do and its code, then presses Add it.
7. To change it, call `extension` again with the same name; added again, it takes the earlier one's place and keeps what it stored.

## What it reaches

- `on(event, match, run)`, `match` optional, an object of values the event must hold:
  - `task.start`: a task begins, `{ task, from }`.
  - `file.add`: a message shared a file, `{ task, file }`.
  - `tool.check`: an action is about to run, `{ name, kind, args, title }`; kinds are read, edit, search, execute, think, fetch, move, delete and other.
  - `turn.end`: an answer ended, `{ task, answer }`.
  - `record`: something was kept in a conversation, `{ task, type, record }`.
- `run(e, next)`: `await next(e)` gives what the rest decided; return it, or on `tool.check` return `{ decision: 'ask' | 'never', reason }` or `{ refuse: reason }` with `refuse`, `{ decision: 'allow' }` with `loosen`.
- `$.slot(name, draw)` for `above`, `answer` (given `{ text }`) or `settings`; `draw` returns a string, `{ text, muted: true }`, `{ text, label }`, `{ row: [...] }`, `{ markdown }`, `{ button, action }`, or null for nothing.
- `$.press(handler)` hears a button's `action`; `$.redraw()` draws it again; `$.notify(text)`; `$.store.get(key)` and `$.store.set(key, value)` keep what it needs.

## Example

```js
export async function register(on, $) {
  let count = (await $.store.get('count')) ?? 0
  on('turn.end', async (e, next) => { count++; await $.store.set('count', count); $.redraw(); return next(e) })
  $.slot('settings', () => ({ row: [new Intl.NumberFormat().format(count) + ' answers', { button: 'Start again', action: 'reset' }] }))
  $.press(async (action) => { if (action === 'reset') { count = 0; await $.store.set('count', 0); $.redraw() } })
}
```
