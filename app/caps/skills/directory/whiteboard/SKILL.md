# Make a whiteboard

A whiteboard holds short notes in named sections, which the user and others move, write and draw on, live. Make one with `whiteboard`, change one with `whiteboard_change`, and read one with `table_rows`. Don't ask first: decide what the request leaves open.

## Steps

1. Take what the request gives: what the board is for, the ideas, tasks or feedback it holds, who does what and by when, and the language.
2. Name a few sections first, three to seven, in the user's language: by time for a plan (Week 1, Week 2…), by question for a retrospective (Went well, To change, To try), by theme for ideas.
3. Then the notes, a few words each, each in one section, never two ideas on one note. An owner and a date only where the user gave them.
4. To sort the notes of a whiteboard open beside the task, read it with `table_rows` first, then move each note by its id to a section by its id, or to a new name, which makes the section. Leave the notes someone put on the open ground where they are. Never make another whiteboard for the same notes.
5. Hand it over in one line: its sections and how many notes. The user accepts or rejects what you changed, on the board.

Jean places what it makes; it never says where a note lies, and neither reads nor makes drawings: say so when asked.
